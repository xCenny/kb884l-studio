# Changelog

## 0.1.0 — 2026-11-18

Initial public desktop release.

- Five Now Bar layouts with six themes, album-based colors and Dual-layout wallpapers.
- Windows media session metadata, CPU/RAM snapshots, GIF import/export and direct verified-device HID upload.
- Static, eight-frame, sixteen-frame and prepared device-loop modes.
- English/Turkish application, tray, backend and built-in display text; generic public defaults.
- Read-only demo mode and a rendered screen gallery.
- Serialized USB transactions, reconnect recovery, bounded retry delays and graceful exit after transfer.
- Optional tray/startup, safe first-launch defaults and local preferences.
- Reproducible Windows build, isolated tests and release checksums.

Firmware modification, native semantic LCD updates, loading-free refresh and notification integration are not included.
